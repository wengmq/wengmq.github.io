本节创建必要的虚拟网络以支持实例启动。网络选项 1 包含一个提供商（外部）网络和一个使用该网络的实例。网络选项 2 包含一个提供商网络（一个使用该网络的实例）和一个自助服务（私有）网络（一个使用该网络的实例）。

本节中的说明使用控制器节点上的命令行界面 (CLI) 工具。但是，您也可以在任何安装了这些工具的主机上按照这些说明操作。

有关 CLI 工具的更多信息，请参阅 [Pike 的 OpenStackClient 文档](https://docs.openstack.org/python-openstackclient/pike/cli/command-objects/server.html#server-create)、 [Queens 的 OpenStackClient 文档](https://docs.openstack.org/python-openstackclient/queens/cli/command-objects/server.html#server-create)或 [Rocky 的 OpenStackClient 文档](https://docs.openstack.org/python-openstackclient/rocky/cli/command-objects/server.html#server-create)。

要使用仪表板，请参阅 [Pike 仪表板用户文档](https://docs.openstack.org/horizon/pike/user/)、 [Queens 仪表板用户文档](https://docs.openstack.org/horizon/queens/user/)或 [Rocky 仪表板用户文档](https://docs.openstack.org/horizon/rocky/user/)。

## 创建虚拟网络[](https://docs.openstack.org/install-guide/launch-instance.html#create-virtual-networks "链接到此标题")

根据您在配置 Neutron 时选择的网络选项创建虚拟网络。如果您选择选项 1，则仅创建提供商网络。如果您选择选项 2，则创建提供商网络和自助服务网络。

- [供应商网络](https://docs.openstack.org/install-guide/launch-instance-networks-provider.html)
- [自助服务网络](https://docs.openstack.org/install-guide/launch-instance-networks-selfservice.html)

为您的环境创建合适的网络后，您可以继续准备环境以启动实例。

## 创建 m1.nano 口味[](https://docs.openstack.org/install-guide/launch-instance.html#create-m1-nano-flavor "链接到此标题")

最小的默认配置每个实例占用 512 MB 内存。对于计算节点内存小于 4 GB 的环境，我们建议创建`m1.nano`每个实例仅需 64 MB 内存的配置。此配置仅可用于 CirrOS 镜像的测试。

```
openstack flavor create --id 0 --vcpus 1 --ram 64 --disk 1 m1.nano

+----------------------------+---------+
| Field                      | Value   |
+----------------------------+---------+
| OS-FLV-DISABLED:disabled   | False   |
| OS-FLV-EXT-DATA:ephemeral  | 0       |
| disk                       | 1       |
| id                         | 0       |
| name                       | m1.nano |
| os-flavor-access:is_public | True    |
| properties                 |         |
| ram                        | 64      |
| rxtx_factor                | 1.0     |
| swap                       |         |
| vcpus                      | 1       |
+----------------------------+---------+
```

## 生成密钥对[](https://docs.openstack.org/install-guide/launch-instance.html#generate-a-key-pair "链接到此标题")

大多数云镜像支持[公钥认证](https://docs.openstack.org/install-guide/common/glossary.html#term-public-key-authentication)而非传统的密码认证。启动实例之前，您必须将公钥添加到计算服务中。

1. 获取`demo`项目凭证：
    
```
    . demo-openrc
```
    
2. 生成密钥对并添加公钥：
```
    
    ssh-keygen -q -N ""
    openstack keypair create --public-key ~/.ssh/id_rsa.pub mykey
    
    +-------------+-------------------------------------------------+
    | Field       | Value                                           |
    +-------------+-------------------------------------------------+
    | fingerprint | ee:3d:2e:97:d4:e2:6a:54:6d:0d:ce:43:39:2c:ba:4d |
    | name        | mykey                                           |
    | user_id     | 58126687cbcc4888bfa9ab73a2256f27                |
    +-------------+-------------------------------------------------+
```
    
    
    或者，您可以跳过该`ssh-keygen`命令，直接使用现有的公钥。
    
3. 验证密钥对是否已添加：
    
```
    openstack keypair list
    
    +-------+-------------------------------------------------+
    | Name  | Fingerprint                                     |
    +-------+-------------------------------------------------+
    | mykey | ee:3d:2e:97:d4:e2:6a:54:6d:0d:ce:43:39:2c:ba:4d |
    +-------+-------------------------------------------------+
    

```
## 添加安全组规则[](https://docs.openstack.org/install-guide/launch-instance.html#add-security-group-rules "链接到此标题")

默认情况下，`default`安全组应用于所有实例，并包含阻止对实例进行远程访问的防火墙规则。对于诸如 CirrOS 之类的 Linux 镜像，我们建议至少允许 ICMP（ping）和安全外壳协议 (SSH)。

- 向安全组添加规​​则`default`：
    
    - 允许[ICMP](https://docs.openstack.org/install-guide/common/glossary.html#term-Internet-Control-Message-Protocol-ICMP)（ping）：  
        允许 [ICMP](https://docs.openstack.org/install-guide/common/glossary.html#term-Internet-Control-Message-Protocol-ICMP) （ping）：
        
```
        openstack security group rule create --proto icmp default
```
