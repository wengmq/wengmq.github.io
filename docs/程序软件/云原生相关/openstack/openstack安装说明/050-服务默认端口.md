为了正常运行，某些 OpenStack 组件依赖于其他非 OpenStack 服务。例如，OpenStack 控制面板使用 HTTP 进行非安全通信。在这种情况下，您必须配置防火墙以允许与 HTTP 之间的流量往来。

下表列出了其他 OpenStack 组件使用的端口：

|服务|默认端口|使用者|
|---|---|---|
|HTTP|80|OpenStack 控制面板（`Horizon`）当未配置为使用安全访问时。|
|HTTP 备用|8080|OpenStack对象存储（`swift`）服务。|
|HTTPS|443|任何启用了 SSL 的 OpenStack 服务，特别是安全访问仪表板。|
|rsync|873|OpenStack 对象存储。必需。|
|iSCSI 目标|3260|OpenStack 块存储。当使用 LVM 和 iSCSI 目标（tgt、LIO、iSER）时需要。|
|NVMe-oF 目标|4420|OpenStack 块存储。当使用 LVM 和 NVMe-oF 目标平台 (nvmet) 时需要。|
|MySQL数据库服务|3306|大多数 OpenStack 组件。|
|消息代理（AMQP 流量）|5672|OpenStack 块存储、网络、编排和计算。|

在某些部署环境中，服务使用的默认端口可能位于主机定义的本地端口范围内。要检查主机的本地端口范围：

```
sysctl net.ipv4.ip_local_port_range

```
如果某个服务的默认端口在此范围内，请运行以下程序检查该端口是否已被分配给其他应用程序：

```
lsof -i :PORT
```

如果默认端口已被其他应用程序占用，请配置服务使用其他端口。
